# python-method-overriding-super
A Python OOP project demonstrating inheritance, method overriding, and the use of super() to extend parent class functionality with a default bus seating capacity.
<br>
Topics Covered
<br>

1. Object-Oriented Programming (OOP) – Organizing programs using classes and objects.
2. Inheritance – Creating a child class (Bus) from a parent class (Vehicle).
3. Method Overriding – Redefining the parent's seating_capacity() method in the child class.
4. super() Function – Calling the parent class method from the child class.
5. Default Parameters – Setting the default seating capacity to 50.
6. Constructor (__init__) – Initializing object attributes.
7. Code Reusability (DRY Principle) – Reusing parent class functionality without duplicating code.
8. Type Hints – Specifying expected argument types.
9. Docstrings – Documenting modules, classes, and methods.
10. Object Instantiation – Creating a Bus object and calling its methods.
